ABDUL MUTHALIP M. — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract this ZIP file.
2. Open index.html in a modern web browser.
3. For best results, keep the assets folder beside index.html and stay connected to the internet for the Google Fonts.

HOW TO PUBLISH
- GitHub Pages: upload the contents of this folder to a GitHub repository, then enable Pages in repository Settings.
- Netlify: drag the extracted folder into Netlify's manual deploy area.
- Any static web host: upload index.html, style.css, script.js, and the assets folder together.

CUSTOMIZE
- Replace the profile photo at assets/profile.jpg if you want a different portrait.
- Edit index.html to add your email address, phone, LinkedIn, GitHub, actual technology stack, and project screenshots.
- The hospital project modules are presented as planned/core areas based on the short description supplied; update them to match the features you have actually implemented.
- Certificate images are stored in assets and open in a new tab when clicked.

This is a static front-end portfolio. It does not include a working hospital database application or backend.
